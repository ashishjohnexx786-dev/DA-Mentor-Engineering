A complete Course 3 engineering route: C3-00–C3-09, 140 controlled lessons, practical labs, revision/mastery surfaces, protected Gate evidence and a production capstone/engineering-transition phase. Start with **How to study**, then C3-00-L01. The Mentor includes mapped lesson text, instructor/official source assignments, final Astra learner assets, practical routes and optional browser-local progress.

## Study flow

Watch the assigned instructor or official source when one is mapped, understand the engineering model, build the task yourself, save evidence and validate the result. Protected reviews are opened only after a genuine saved attempt; repair the weakness, close the review, then complete the changed/fresh retry required by that assessment.

The Mentor records your study decisions and evidence. It does not automatically grade competence and does not replace native PostgreSQL, Python, dbt, Airflow, Spark, Kafka, Fabric/cloud or other runtime evidence.

AMOLED and light themes, adjustable reading size and an optional stopwatch are available in Settings. Export progress to transfer between devices; phone and PC do not synchronize automatically. Videos require access to their original provider. Browser-cached pages/assets may remain available offline after they have been visited; large repository/course downloads use the network.

Download the current repository/course package from Settings. Read VERIFICATION.md for static checks and native-runtime limits. No generated video lessons are included.

## Repository layout

- index.html, styles.css, app.js: current Standalone-DE-style Mentor interface.
- curriculum.json and data/: the single current Course 3 curriculum and lesson/companion data.
- assets/: final learner books, Astra companion surfaces, labs/practice and protected-review assets.
- manifest.webmanifest, sw.js: scoped PWA/offline shell.
- icon.svg: current Course 3 Mentor icon.
- release.json: public edition marker.
- VERIFICATION.md: verification scope and remaining native-runtime limits.

The current branch is the active Mentor generation; obsolete legacy UI/state/cache files are not part of the current live tree. Earlier Git commits are repository history, not active Mentor files.

Local progress uses the edition-specific key `course3-de-2026-study-astra-v2`. Export a backup before clearing browser data or changing devices.
